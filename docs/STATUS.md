## 已知错误或风险

- `web_interface/config.py` 包含公开默认登录密码和固定 Flask secret；部署时应通过忽略提交的 `local_config.py` 覆盖。
- `raspi-setup.sh` 直接安装系统包并写入 systemd，尚未在目标 Raspberry Pi OS 版本上验证。
- Motor Shield Rev3 类 L298P 驱动存在压降和发热，必须用实际电机的工作/堵转电流核验余量。
- 七个舵机同时动作会产生较大峰值电流；禁止从 Arduino USB/5V 供电，应使用独立5–6V高电流电源并共地。
- 原项目电机为开环控制，没有编码器闭环；左右速度偏差需要机械检查和参数补偿。
- 310个打印件中大量为履带零件，打印失败、配合公差和装配返工可能成为主要工期风险。
- 代码当前没有自动化测试，真实硬件行为不能只靠静态检查确认。
